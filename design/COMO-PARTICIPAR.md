# Como participar do site

Você não precisa programar nem instalar nada. Tudo acontece no site do GitHub, e o Claude Desktop ajuda a escrever.

## Uma vez só

1. Crie uma conta em [github.com](https://github.com/signup) e mande seu nome de usuário ao Leandro.
2. Você vai receber um e-mail de convite para o repositório `lugarnenhum`. Clique em **Accept invitation**.
3. No [repositório](https://github.com/leandromesq/lugarnenhum), clique em **Watch** → **Participating and @mentions**. Assim o GitHub te avisa por e-mail quando houver algo para você ver.

## Pedir uma mudança no site

1. No Figma, selecione os frames que mudaram e exporte como PNG (painel **Export** → **PNG** → **Export**). Exporte desktop e celular quando os dois mudarem.
2. Abra o formulário [Mudança de design](https://github.com/leandromesq/lugarnenhum/issues/new?template=mudanca-de-design.yml).
3. Preencha os campos:
   - **O que mudou**: escreva do seu jeito. Se quiser, peça ao Claude Desktop: "me ajuda a descrever esta mudança do site da banda" e cole o texto que ele escrever.
   - **Frames no Figma**: no Figma, clique com o botão direito no frame → **Copy link to selection** e cole aqui.
   - **Exports**: arraste os PNGs para dentro do campo.
4. Clique em **Create**. O Leandro recebe o pedido e responde ali mesmo.

## Revisar o resultado

Quando o Leandro terminar, você recebe um e-mail do GitHub com o título "Screenshots" e o seu nome mencionado.

1. Abra o link do e-mail. As imagens de cada página aparecem no comentário, em computador e em celular.
2. Compare com o Figma. Se quiser ajuda, arraste para o Claude Desktop o screenshot e o seu export e pergunte: "o que está diferente entre o site e o meu design?".
3. Responda no campo de comentário, no fim da página:
   - Se estiver certo, escreva **Aprovado**.
   - Se não estiver, escreva uma linha por ajuste: a página, computador ou celular, e o que deveria mudar. Pode anexar um print marcado.
4. Clique em **Comment**. Cada correção gera novos screenshots e um novo aviso.

O site publicado fica em https://leandromesq.github.io/lugarnenhum/.
